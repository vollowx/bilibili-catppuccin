## Usage

1. Ensure you have Stylus installed.
2. Go to the `catppuccin.user.css` and click the `Raw` button to install/update manually.

## 🙋 FAQ

- Q: **_"Will this be merged into catppuccin/userstyles?"_**\
  A: Due to the chaotic naming of elements in bilibili, this repo is easily breakable and the answer is no.
